# Complete interface localization — ongoing coverage log

The target is every end-user workflow in English, Korean, Chinese, Japanese, Spanish and French,
not just navigation. Each batch includes descriptions, labels, accessibility names, validation,
progress, empty/error states, review and save/retry. User-authored names, SKUs, model identifiers,
API values and stored data are not translated. Raw technical diagnostics remain available unchanged
under a translated disclosure, with localized actionable guidance above them. Model-generated
language and server-returned domain explanations require separate coverage; do not count them as done.

## Batch 1: uploaded photos → reviewed layout

The entire LibraryPhotos dialog uses the existing locale store: entry/title/description, explanatory
copy, replacement toggle, search, selection counters, all menu options, empty/loading states, image
alternative text, preview, saving/retry/open and limits. Complete sentences interpolate values without
translating user content. Validation stores message keys until render so switching language updates
an already-visible error. No locale is added to the API request or query identity.

The shared DialogFooter had an English-only Close button even though DialogContent's dismissal was
localized. Both now follow the selected language. Shared RequestError supplies translated HTTP-status
guidance and a translated technical-details disclosure; the diagnostic text itself is preserved.

Validation evidence is recorded after actual runs; local logs are under
`/workspace/.verification/twinstore-i18n/`. Basic existing photo/i18n suites: 51 passed. The separate
boundary phase adds all-six-language save/open tests, language changes during pending preview and
uncertain saves, selection/filter/request-ID preservation, literal user names and error retranslation.
An initial test clicked before a QueryClient notification was rendered and saw a stale-preview alert;
the test now waits for the empty-library state before exercising the missing-photo validation. This
was a test synchronization error, not a product defect.

Browser review also caught awkward singular/plural text such as French `1 produits`. Count summaries
now use labels (`Produits : 1`) instead of appending a fixed plural noun. Related suites passed again
after this copy fix. The shared footer's untranslated dismissal is covered in all six languages.
