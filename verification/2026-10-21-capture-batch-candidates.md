2026-10-21. Document/code-based requirements hypotheses, not interviews or measured time savings.

Checked sources (HTTP 200): [NN/g recognition and recall](https://www.nngroup.com/articles/recognition-and-recall/) supports visible choices; [NN/g user control and freedom](https://www.nngroup.com/articles/user-control-and-freedom/) recommends exits and undo; [Shopify bulk editing](https://help.shopify.com/en/manual/products/bulk-editing) redirected to Products documentation describing editing multiple products together; [MDN multiple](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/multiple) documents multi-file selection. | Candidate / users | Current friction and gap | Inputs / feasibility | Verification |
| --- | --- | --- | --- |
| Combine reviewed shelf photos / operators building a real-store twin, marketers preparing alternatives | Capture UI applies one photo at a time, producing intermediate child layouts; backend has multi-capture placement but no batch UI or preview | Existing completed captures and one base layout; no extra model call. | Natural-language starter / marketers and researchers exploring a store concept | Many layout options require setup knowledge | Existing generation/models; explicit interpretation preview, provider readiness and reliable constraint handling required | Unsupported requests, uncertain defaults, costs and reproducibility; larger than this cycle |

Selection: connect reviewed photos to one combined draft. Keep source layouts and captures intact; show photo thumbnails and warnings instead of requiring CSV input. Preview the same placement computation used to save, bind it to source content, and make uncertain save retries idempotent. Save one new draft only; opening it is an explicit user action. No promise of exact room geometry from shelf photos: existing grid placement preserves shelf ordering/facings within capacity. Do not silently drop products. Estimated/unrecognized inputs stay visibly marked. Do not infer missing prices as measured values.

Initial integration: main 0e48656e, scenarios 7be4b9b0, edge-case fixes 0308e167; operator 1155cc12 preserved. Updated AGENTS localization scope read. Capture UI remains English; localized layout navigation is untouched.

Boundary-informed selection details: exact complete-name matching replaces fuzzy matching only in this batch workflow, to avoid collapsing similarly named variants. The existing grid engine can scale facing counts down even when no complete product is dropped; the new preview reports original/placed counts and requires explicit acceptance of any reduction. Missing prices are flagged and their grid zero is documented as a placeholder. No measured task-completion speed or recognition accuracy is claimed.
