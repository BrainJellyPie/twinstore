TwinStore v0.8.0 improves small-screen layouts across the six interface
languages, announces finished runs, and identifies changes that a local model
described but did not apply.

- **Know when a run is done.** If an online run or a store simulation finishes
  or fails while you are on another page, a notice in the corner names it and
  opens its report or results, on the right layout.
- **A finished run opens on its results.** Before the day plays, the store's
  Results tab leads with what the run found (revenue and shoppers) and a link
  to its totals, instead of a wall of zeros.
- **Keyboard shortcuts.** Press **?** anywhere outside a text field for a
  sheet of every key that works without the mouse; on the store floor **←** and
  **→** step the day back or forward 15 minutes.
- **Both analysts know both channels.** A store run's analyst now reads how the
  same customers bought online, as the online analyst already read the store
  run, and the online report's **Store and online** section opens the store run
  it compares with.
- **The designer says what it did not change.** When a small local model's reply
  describes changes it never made (a real 450M model described six), the reply
  carries **Mentioned but not changed** chips. Every model wait says after 15
  seconds that a small local model can take minutes, with the time so far.
- **Small-screen layouts.** Improve clipped and overflowing text at 360 px
  across the six languages: the shelf
  test form, conjoint rows, marketing lift charts (whose interval shrank to a
  dot on a phone), the online run form, shopper cards, the store cards' links
  and 60 responsive grids have more usable space. Long names show on hover.
- **Status contrast and accessible labels.** Darker green, red and amber status
  text improves light-mode contrast. The playback progress bar has an accessible
  name, and the local-model hardware panel uses a valid definition list.
- **Structured local-model answers.** Generated customer budgets use explicit
  currency amounts, converted exactly into stored units. Shelf judgments wrapped
  in `properties` are recovered when they contain actual values; copied schemas
  and missing interest scores remain errors. Model factual mistakes still need
  review.
- **Smaller fixes.** The store's customer mix reads as share bars, the
  marketing A/B report uses its width, the neighborhood
  legend no longer lets the map show through, phone visitors browse an online
  store's mobile page first, store names are limited to 200 characters, and
  small local models get constrained layout, format and product choices so a
  bakery is not started as a convenience store.
